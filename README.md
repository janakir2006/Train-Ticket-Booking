Train Ticket Booking App
Description

This is a web application for booking train tickets. Users can search for trains, book tickets, and manage their bookings easily.

Tech Stack

Frontend: HTML, CSS
Backend: Flask (Python)
Database: PostgreSQL

Features
Search trains
Book tickets
View bookings
Cancel tickets
User login and registration
How to Run
Clone the project
git clone https://github.com/your-username/train-ticket-booking.git
Install dependencies
pip install -r requirements.txt
Run the application
python app.py
Open in browser
http://127.0.0.1:5000/
